What does this do?Fills each posting (for sale by owner) — title, price, description, location, and photos. With Publish automatically checked, it clicks Craigslist’s publish button for you too, stopping to let you finish first if Craigslist asks for phone or email verification. Uncheck to review and publish it yourself.

What does this do?Gumtree Australia requires signing in before any part of the posting form can be seen, so this can’t be autofilled yet. Opens the posting page, waits for you to sign in, then shows the item’s title, price, description, and photo links so you can paste them into Gumtree’s form yourself — click “I posted” when you’re done so FindA.Sale can track it.

What does this do?Fills the Poshmark listing form as best it can — category, brand, size, and condition are best-effort guesses (CODE-ONLY, not yet verified against a real Poshmark account). With Publish automatically checked, it clicks Next then Poshmark’s own List this item button for you, publishing with its best guess even on a low-confidence category (flagged in a summary at the end of the run so nothing is silently missed). Uncheck to review and publish it yourself. If the form looks empty, Poshmark may need a recent sign-in through its mobile app first.
What does this do?Uploads photos first (Mercari fills some fields itself right after), then fills the rest — category, brand, and shipping weight are best-effort guesses (CODE-ONLY, not yet verified). Uncheck to review and publish it yourself.
What does this do?Fills one new Vinted listing at a time — category, brand, material, and package size are best-effort guesses (CODE-ONLY, not yet verified). Click Vinted’s own Upload button yourself — this channel never publishes automatically, and never reposts a listing on its own.
What does this do?Fills the Grailed listing form as best it can, but leaves measurements blank for you to add (Grailed listings perform better with them) and skips an item entirely if its brand isn’t a match on Grailed’s designer list (CODE-ONLY, not yet verified). With Publish automatically checked, it clicks Grailed’s own List item button for you — unless the Designer field couldn’t be confirmed, which always stops for your review first. Uncheck to review and publish every item yourself.

What does this do?Checked every ~20 min. When an item sells elsewhere, the extension removes its listing on Facebook, Poshmark, Mercari, Vinted, Grailed, and Gumtree Australia — “Remove automatically” runs in a background tab, “Notify me” waits for you to click the alert first. (Craigslist isn't covered yet — it has no persistent "my postings" page to check, so it can't be auto-removed the same way.) The same check also looks the other way for Facebook specifically: if an item sells right there on Facebook, it's marked sold on FindA.Sale automatically (and its eBay listing withdrawn) — no extra setup, it uses this same setting. That reverse check isn't built yet for the other platforms. When you change an item's price on FindA.Sale, you'll also get a notification to update it on Facebook yourself — automatic price updates aren't built yet, so this always just notifies for now, even in “Remove automatically” mode. “Off” turns off all of the above.
