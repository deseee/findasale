Checked every ~20 min. When an item sells elsewhere, the extension removes its Facebook listing — “Remove automatically” runs in a background tab, “Notify me” waits for you to click the alert first. The same check also looks the other way: if an item sells right there on Facebook, it's marked sold on FindA.Sale automatically (and its eBay listing withdrawn) — no extra setup, it uses this same setting. When you change an item's price on FindA.Sale, you'll also get a notification to update it on Facebook yourself — automatic price updates aren't built yet, so this always just notifies for now, even in “Remove automatically” mode. “Off” turns off all of the above.
