# Health Report — 2026-05-10

## Summary

Overall health is **Yellow**. No critical secrets exposure or auth bypasses found. CORS and admin route protections are solid. The main concerns this week are: (1) ten env vars present in `.env.example` are missing from the production `.env` — several are actively used with no fallback; (2) a voice-input code path in `add-items/[saleId].tsx` unconditionally overwrites organizer-set prices with AI estimated values, violating the organizer-values-win rule; and (3) five UI pages use native `alert()` for user feedback instead of toast components. The 239 unbounded `findMany` calls are mostly internal/admin or already have `take:` limits at the public query level. The 107 TODO/FIXME markers are tracked for awareness but not urgent individually.

### H-002 — Voice input unconditionally overwrites organizer-set price (Organizer Intent Rule Violation)
**File:** `packages/frontend/pages/organizer/add-items/[saleId].tsx:1359`  
**Pattern:**
```ts
price: estimatedPrice ? estimatedPrice.toString() : prev.price,
```
This replaces `prev.price` (organizer's explicitly entered value) with the AI estimate whenever `estimatedPrice` is truthy — no check for whether the organizer already set a price. This directly violates the locked rule: "organizer explicit values beat AI fallbacks everywhere."  
**Contrast:** `VoiceDescriptionInput.tsx:160` correctly checks `!existingFields.price` before filling.  
**Action:** Change the line to: `price: estimatedPrice && !prev.price ? estimatedPrice.toString() : prev.price` — dispatch to `findasale-dev` for surgical fix.

### M-003 — Login page reads `window.location.search` inside async event handler (SSR Safety)
**File:** `packages/frontend/pages/login.tsx:35,79`  
Both `handleSubmit` and `handlePasskeySignin` call `new URLSearchParams(window.location.search)` directly. These run inside event handlers (client-only), so SSR is not actually broken here — but should use `router.query.inviteToken` for consistency with Next.js patterns and to avoid any future SSR regression if the handler is ever called outside a click context.
