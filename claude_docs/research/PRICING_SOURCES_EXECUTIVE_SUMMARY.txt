FindA.Sale Multi-Source Pricing Engine Research
EXECUTIVE SUMMARY FOR PATRICK
April 25, 2026

================================================================================
THE SITUATION
================================================================================

PriceCharting + eBay covers ~15-20% of estate sale listings (collectibles only).
Furniture, tools, decor, appliances have different pricing patterns entirely.

Problem: AI pricing is off by 50-300% on non-collectible items because there's
no single source covering estate sales like EBTH or auctions.

ItsDeductible (Intuit's FMV database) is DEAD as of October 2025.
Xactware is enterprise insurance-only (not accessible).
You NEED 4-5 integrated sources to get reasonable coverage.

================================================================================
THE SOLUTION: 3-TIER ENGINE
================================================================================

TIER 1 - HIGH CONFIDENCE (Real Sold Prices)
------------------------------------------
1. PriceCharting (existing) - collectibles/games
2. eBay Browse API (existing) - broad coverage
3. EBTH / MaxSold Scraper (BUILD THIS) - estate sale furniture/decor ← BIGGEST GAP
4. Keepa API (add) - electronics/appliances with ASIN

TIER 2 - GOOD PROXY (Recent Market Data)
----------------------------------------
1. GSA Auctions API (add, FREE) - tools/equipment/office furniture
2. B-Stock API (if partnership) - appliances/electronics/returns baseline
3. OfferUp Scraper (optional) - local furniture comps

TIER 3 - BASELINE/FLOOR (Category Estimates)
---------------------------------------------
1. Salvation Army Donation Guide (free) - furniture/appliances generic baseline
2. Storage Treasures (free) - distressed furniture floor pricing
3. The Real Real Report (free) - luxury goods depreciation curves
4. Michigan Probate Records (one-time research) - estate appraisal calibration

================================================================================
WEIGHTING ALGORITHM (How to Combine Sources)
================================================================================

Collectible item?
  → PriceCharting 60% + eBay 40%

Has ASIN + Keepa comps?
  → Keepa 50% + eBay 50%

Furniture/decor/tools + EBTH comps?
  → EBTH 70% + eBay 30%

Tools/equipment + GSA comps?
  → GSA 40% + eBay 60%

No comps found?
  → Salvation Army Donation Guide (floor price)

Key principle: More sources = higher confidence. Always prefer Tier 1 (sold prices)
over Tier 2 (market data) over Tier 3 (estimates).

================================================================================
CRITICAL GOTCHAS
================================================================================

1. SOLD ≠ ASKING
   - eBay "sold listings" are asking prices with shipping
   - EBTH/auctions are TRUE hammer prices (real market)
   - Don't weight them equally

2. CATEGORY SEGMENTATION MATTERS
   - Furniture depreciates 20-30%/year
   - Electronics depreciate 40-60%/year
   - Tools depreciate 5-10%/year (brand-name tools hold value)
   - Don't cross-apply pricing across categories

3. DEPRECIATION CURVES ARE YOUR BIGGEST NEED
   - Build via Michigan probate study or manual research
   - A couch in "good condition" might be $200-400 depending on age/style
   - Condition assessment is critical (off by 1 level = 30-50% pricing error)

4. ESTATE SALES HAVE UPWARD BIAS
   - EBTH/MaxSold are high-end estate sales (estate professionals)
   - Yard sale pricing can be 20-40% lower
   - Account for this in category-specific curves

5. LIQUIDATION CONTEXT DISTORTS PRICES
   - B-Stock/storage auctions = distressed sellers
   - Don't apply to normal secondary market
   - Use only for specific categories (electronics returns, bulk tools)

================================================================================
SOURCES TO SKIP (Dead Ends)
================================================================================

- Xactware: Enterprise insurance-only, no API, not accessible
- ItsDeductible: DEAD (shut down October 2025)
- Invaluable: Art/antiques only, partner API only, too niche
- WorthPoint: Antiques only, no API, expensive subscription
- Kovels: Redundant with WorthPoint, no API
- Replacements.com: China/flatware only, too niche
- NARTS/NAA: No pricing data
- Allied/United/Atlas movers: Data is proprietary, not public
- Poshmark/Depop: No official API, TOS-risky scraping, asking prices only
- ThredUp/The Real Real: Aggregate reports only, no item-level data
