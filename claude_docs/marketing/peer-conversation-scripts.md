## General Messaging Rules (For All Scripts)

- Never use "AI" — use "auto-tags," "smart pricing," "suggested"
- Always include specific numbers (27 minutes, 150 items, 10% fee)
- Acknowledge limitations (not for tiny one-time garage sales, still requires photography, etc.)
- Be honest about the commission (it's 10%, which is competitive, but it's not free)
- Celebrate all sale types equally (don't position estates as the "real" ones)
- Personalize with real organizer names and actual experiences
- If you're an advisor, mention it (transparency builds trust)
